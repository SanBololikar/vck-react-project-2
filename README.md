# 🎓 Vivekanand College, Kolhapur (VCK) - Informative Web Portal

### 🏢 Developed during OJT at WallStar, Kolhapur

**VCK-React-Project-2** is a professional-grade, responsive web application developed to serve as a digital information hub for **Vivekanand College (Empowered Autonomous), Kolhapur**. This project focuses on high-performance static content delivery, modern UI/UX principles, and a clean architectural pattern.

---

## 💼 Professional Context
This project was conceptualized and developed during my **On-the-Job Training (OJT)** at **WallStar, Kolhapur**. Under professional mentorship, I applied industry-standard React workflows to bridge the gap between academic information and modern web accessibility.

## 🚀 Key Features

* **Dynamic Routing:** Seamless navigation between college departments, administration, and campus facilities using `react-router-dom`.
* **Responsive Architecture:** A mobile-first design approach ensuring compatibility across all device breakpoints (Mobile, Tablet, Desktop).
* **Optimized Assets:** High-resolution imagery and SVG icons managed through a structured assets pipeline.
* **Component-Based UI:** Reusable, modular components (Navbar, Footer, Info-Cards) to ensure code maintainability and scalability.
* **Informative Modules:** Detailed sections for:
    * Academic Programs & Departments
    * Campus Infrastructure (Library, Labs, Gymkhana)
    * Placement Cell & Student Support
    * Contact & Location Integration
